# C 语言学习笔记（在线版）

这是一个用 CNotes 记录的每日 C 语言学习笔记，已导出为**单个自包含网页**并发布在 GitHub Pages 上，可直接在线浏览全部内容（文字 + 图片）。

## 在线阅读

```
https://castoricelover777.github.io/cnotes-notebook/
```

或直接查看仓库里的 [index.html](./index.html)。

## 内容

- **100 条笔记**，覆盖 21 个学习日
- 每条笔记包含：标题、知识点、学习笔记、C 语言代码、复盘、课程总结
- **85 张图片**已全部内嵌（含代码截图、练习题等）
- 页面带目录导航，可点击跳转到具体某一天

## 说明

- 本仓库只包含**笔记内容导出**（网页），不含 CNotes 应用源码。
- 网页为**纯静态、自包含**，可下载到本地双击打开，无需安装任何软件。
- 笔记由作者本人记录，如引用请注明出处。
